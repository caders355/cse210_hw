Journal Program:
    1. The program provides journal prompts, takes user input, then saves the question, input, and date to a file.
    2. The program should be able to take journal entries (string) as user input.
    3. The program should save user input, a program-generated prompt, and the date to a file.
    4. The program should only end when a user is done, as they should be able to view all journal entries.

Classes (besides core Program):
    1. Journal
        a. store entries
        b. save new entries to file
        c. load previous entries from file
        d. display all entries
            -> _entries [List<Entry>]
            ==> AddEntry(newEntry) [void]
            ==> DisplayAll() [void]
            ==> SaveToFile(file) [void]
            ==> LoadFromFile(file) [void]
    2. PromptGenerator
        a. randomly choose a prompt
        b. return prompt to be displayed to user
            -> _prompts [List<string>]
            ==> GetRandomPrompt() [string]
    3. Entry
        a. compiles date, prompt, and user input into an Entry
            -> _date [string]
            -> _promptText [string]
            -> _entryText [string]
            ==> Display() [void]

Program Flow:
    1. Initialize Journal and PromptGenerator
    2. Loop Menu
        a. Option to Write -> calls PromptGenerator, gets user input, creates Entry object, and passes to Journal
        b. Option to Display -> loops through _entries and displays on each Entry
        c. Option to Load -> ask for filename and loads
        d. Option to Save -> ask for filename and saves
        e. Option to Quit -> exits loop for menu
